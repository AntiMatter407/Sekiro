## 用户需求

从本地原版只狼游戏资产中提取并导入敌我血量条、架势条及锁定 UI，按原版排版和视觉结构实现游戏内显示。
使用原版锁定标记替换现有程序绘制的圆环/刻线，不改变现有锁定目标选择、相机及输入规则。
资源数值继续由 GAS 的统一 Character AttributeSet 提供，UI 不另存权威血量、上限或架势参数。

## 范围

- 主角生命条、架势条及其背景、边框、填充、变化反馈。
- 普通敌人、精英/Boss 的生命和架势显示，区分目标跟随 UI 与固定 HUD；具体显隐按原版证据实现。
- 原版锁定标记的纹理、尺寸、颜色、位置、动画和显隐，替换旧程序绘制外观。
- 原版资源包 → 素材清单/图集映射 → UE Texture/Material/Widget → GAS/Survival 数据绑定。
- 原版基准分辨率和锚点、DPI、安全区域、宽屏适配及可追溯的视觉验收。
- 可在 LuaGameplay 顶层菜单增加“原版战斗 UI 资源导入”编辑器入口；具体路径和映射由项目配置提供，插件只承担通用导入能力。

不包含道具栏、金币、经验、技能、完整菜单系统或伤害飘字。
不新增 Boss 阶段权威、忍杀节点数量或回生次数；如原版 UI 的这些元素需要展示，必须等待对应真实数据源，不得由血量猜测。
不执行原版 GFX 脚本，不把原版完整游戏目录作为运行时依赖。

## 验收条件

- 每个正式显示元素能追溯到原版资源/图集区域，没有用占位色块冒充原版素材。
- 双方 Health/MaxHealth 与 Posture/MaxPosture 正确绑定，UI 不修改属性或计算伤害、恢复。
- 排版、比例、填充方向、边框、透明度和显隐有原版证据及对照，不能只以“看起来相似”验收。
- 锁定后只出现一套原版标记，跟随当前目标；失锁/销毁后及时隐藏，不残留上一目标的位置或数值。
- 最大值变化、首次初始化、复活和目标切换不会短暂显示默认满血或上一目标数据。
- 屏幕分辨率/DPI 变化时比例和安全边距稳定，不重复换算像素坐标。
- 正常 HUD 不抢鼠标焦点、不切换游戏输入模式，专用服务器不创建本地 UI。
