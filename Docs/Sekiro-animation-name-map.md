## 命名规则

- 若 `eventnameid.txt` 中出现类似 `a000_000010.hkx_WC`，则将其记为**精确标签**，可信度为 **高**。
- 若未出现精确标签，但属于基础 `a000_000xxx` 常见 locomotion 片段，则给出**工作命名**，可信度为 **低**。
- 其余大量战斗、义手、武器、状态衍生动作，当前先保留原始 `Sekiro_xxx_xxxxxx`。
