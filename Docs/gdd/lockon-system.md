# 锁定系统

> **状态**: 草稿
> **最后更新**: 2026-05-30
> **支撑的支柱**: 刀刃对抗、精确节奏

## 概述

锁定系统让玩家锁定一个目标敌人，使移动、攻击和视角自动以目标为参考。基于 UE SpringArm + Camera 机制扩展，提供锁定/切换/解锁功能，以及锁定状态下的视角管理和目标切换规则。

## 玩家幻想

锁定应该"粘"在目标上但不限制视野——镜头始终能看到目标和玩家角色。切换目标应该流畅，玩家不会因为切到身后敌人而迷失方向。解锁后视角立即恢复自由。

## 详细设计

### 核心规则

1. 锁定目标选择：屏幕中心最近的目标（角度和距离加权）
2. 锁定状态：摄像机自动跟踪锁定目标，SpringArm 的 TargetOffset 更新为目标位置
3. 切换目标：右摇杆左右推动切换到相邻目标
4. 解锁：再次按下锁定键、目标死亡、或目标超出最大锁定距离
5. 锁定指示器：目标身上显示白色锁定标记，当前锁定目标显示红色标记
6. 视角限制：锁定状态下 SpringArm 的旋转受限于目标方向 ±45°（水平和垂直）

### 目标选择算法

```
1. 获取屏幕中心点（ScreenCenter = ViewportSize / 2）
2. 对有效范围内的所有敌人：
   a. 计算屏幕投影位置
   b. 角度分数 = 1 - (目标屏幕位置到屏幕中心的角度 / MaxAngle)
   c. 距离分数 = 1 - (距离 / MaxLockOnRange)
   d. 总分 = 角度分数 * 0.6 + 距离分数 * 0.4
3. 选择总分最高的目标
```

### 目标切换

| 操作 | 行为 |
|------|------|
| 右摇杆 → | 切换到当前目标右侧最近的敌人 |
| 右摇杆 ← | 切换到当前目标左侧最近的敌人 |
| 目标死亡 | 自动切换到最近的有效目标，无可选目标则解锁 |
| 目标超出范围 | 自动解锁 |

### 锁定状态管理

```
LockState:
  Unlocked → (按锁定键 + 有效目标) → Locked
  Locked → (按锁定键) → Unlocked
  Locked → (目标死亡/超出范围) → AutoUnlocked
  AutoUnlocked → (0.5s内无可选目标) → Unlocked
  AutoUnlocked → (0.5s内有可选目标) → Locked(新目标)
```

### 与其他系统的交互

| 交互系统 | 数据流向 | 说明 |
|----------|---------|------|
| 输入系统 | 输入锁定/切换指令 | 接收 LockOn 动作 |
| 角色移动 | 输出锁定目标 | 锁定移动的方向参考 |
| 战斗 HUD | 输出锁定状态 | HUD 显示锁定标记 |
| 弹刀/攻击 | 输出锁定目标 | 自动面朝目标 |

## 公式

### 锁定目标打分

```
Score = AngleWeight * (1 - AngleToCenter / MaxAngle) + DistanceWeight * (1 - Distance / MaxRange)
AngleWeight = 0.6, DistanceWeight = 0.4
```

### 锁定断连距离

```
BreakDistance = MaxLockOnRange * 1.2  // 超出锁定范围 20% 才断开
```

## 边界情况

| 场景 | 预期行为 | 理由 |
|------|---------|------|
| 目标死亡 | 自动切到最近有效目标，0.5s 内无目标则解锁 | 保持战斗连续性 |
| 目标瞬移到身后 | 视角平滑跟随（旋转速度 360°/s），不瞬切 | 防止玩家迷失方向 |
| 多个敌人重叠 | 选择距离最近的那个（距离分数打破平局） | 需要一种确定性的选择 |
| 锁定目标被遮挡 | 如果遮挡 > 1s，自动解锁并切换到可见目标 | 防止锁定在墙后的敌人 |
| 无目标时按锁定 | 扫描范围内敌人，选最高分；范围为空则不锁定 | 不应锁定到空气 |
| 剧情/过场中 | 强制解锁，过场结束重新允许锁定 | 过场动画控制视角 |

## 依赖

| 系统 | 方向 | 依赖性质 |
|------|------|---------|
| 输入系统 | 锁定依赖输入 | 锁定/切换按键 |
| 移动系统 | 依赖锁定 | 锁定状态下的移动方向参考 |
| 战斗系统 | 依赖锁定 | 攻击/弹刀自动面朝锁定目标 |
| 战斗 HUD | 依赖锁定 | 显示锁定标记 |
| 数据配置 | 锁定依赖数据配置 | MaxLockOnRange |

## 调优旋钮

| 参数 | 建议默认值 | 安全范围 | 增加的效果 | 减少的效果 |
|------|----------|---------|-----------|-----------|
| MaxLockOnRange | 1500 UE单位 | 800-3000 | 更远锁定 | 更短锁定 |
| BreakDistanceMultiplier | 1.2× | 1.1-1.5 | 更难断开锁定 | 更容易断开 |
| AngleWeight | 0.6 | 0.4-0.8 | 更看重角度（屏幕中心） | 更看重距离 |
| CameraRotationSpeed | 360°/s | 180-540 | 视角跟随更快 | 跟随更慢 |
| ReacquireDelay | 0.5s | 0.2-1.0 | 断锁后重连更慢 | 重连更快 |

## 验收标准

- [ ] 锁定目标后，角色移动和攻击自动面朝目标
- [ ] 右摇杆左右推动能正确切换到相邻敌人
- [ ] 目标死亡后自动切到下一个有效目标（0.5s 内）
- [ ] 目标超出 MaxLockOnRange × 1.2 时自动解锁
- [ ] 解锁后视角立即恢复自由旋转
- [ ] 锁定标记（红色/白色圆点）正确显示在目标身上
- [ ] 无目标时按锁定键不产生任何效果（不崩溃，不锁定无效对象）
