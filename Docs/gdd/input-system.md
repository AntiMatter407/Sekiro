# 输入系统

> **状态**: 草稿
> **最后更新**: 2026-05-30
> **支撑的支柱**: 精确节奏、刀刃对抗

## 概述

输入系统负责将玩家物理输入（键盘/鼠标、手柄）转化为游戏内动作指令。基于 UE5 Enhanced Input System，定义全套战斗操作映射，并提供输入缓冲（Input Buffer）机制以支持精准的连段和弹刀时机判定。输入系统只负责动作指令的发出，不包含动作的实现逻辑。

## 玩家幻想

玩家按下按键时，角色应立即响应且动作精准。输入延迟或"吞键"感会彻底摧毁只狼式精确节奏战斗。每一个按键都应该让玩家觉得角色在完美执行自己的意图。

## 详细设计

### 核心规则

1. 使用 UE5 Enhanced Input System（`UInputAction` + `UInputMappingContext` + `UEnhancedInputComponent`）
2. 所有输入通过 `UInputAction` 资产定义，不在代码中硬编码按键
3. 输入映射分为 Default（键盘鼠标）和 Gamepad 两套 `UInputMappingContext`
4. 提供输入缓冲队列，缓存最近 N 帧的输入供弹刀/连段等系统查询
5. 动作优先级：弹刀/防御 > 闪避 > 攻击 > 使用物品 > 移动
6. 部分动作支持 Hold（蓄力/奔跑）和 Tap（轻击/闪避）双重判定

### 输入动作定义

| InputAction | 类型 | 触发方式 | 说明 |
|-------------|------|---------|------|
| IA_Move | Axis2D | Continuous | WASD/左摇杆，归一化方向向量 |
| IA_Look | Axis2D | Continuous | 鼠标/右摇杆，视角旋转 |
| IA_Attack | Digital | Tap/Hold | 轻击=普攻，Hold=蓄力突刺 |
| IA_Deflect | Digital | Tap | 弹刀/防御（按下即进入防御姿态） |
| IA_Dodge | Digital | Tap + Direction | 方向+闪避=侧闪/后闪；无方向=后闪 |
| IA_Jump | Digital | Tap | 跳跃 |
| IA_UseItem | Digital | Tap | 使用伤药葫芦 |
| IA_LockOn | Digital | Tap | 锁定/切换/解锁 |
| IA_GrapplingHook | Digital | Tap | 钩绳（仅当钩点可用时响应） |
| IA_Pause | Digital | Tap | 暂停菜单 |
| IA_Sprint | Digital | Hold | 按住奔跑（可与 IA_Move 叠加） |

### 输入缓冲 (Input Buffer)

```
缓冲队列容量: 8 个条目
每个条目: { InputAction, Timestamp, Direction(可选) }
缓冲有效期: 输入后 N 帧（由数据配置的 DeflectWindowFrames 等控制）
```

1. 每次合法输入触发时，将 `(Action, GameTime, Direction)` 推入固定大小的循环队列
2. 各战斗系统（弹刀、普攻、闪避）在 Tick 中检查缓冲队列，判断是否有符合时机的输入
3. 动作执行后**不自动清除缓冲**——由各系统自行决定是否消费（例如弹刀消费防御输入，连段消费攻击输入）
4. 缓冲过期后（超过有效期）自动丢弃

### 输入状态机

```
Idle
├── Defense (IA_Deflect Pressed)
│   ├──→ Block (持续按住)
│   └──→ Deflect (精确时机内松开→按下判定为弹刀)
├── Attacking (IA_Attack)
│   └──→ ComboChain (连段窗口内再次按下 → 下一段)
├── Dodging (IA_Dodge)
│   └──→ 根据方向+敌人攻击类型判定侧闪/后闪/识破/踩踏
└── UsingItem (IA_UseItem)
    └──→ 喝药动画 → 可被闪避取消 (原版行为)
```

### 与其他系统的交互

| 交互系统 | 数据流向 | 说明 |
|----------|---------|------|
| 角色移动 | 输出 IA_Move, IA_Jump, IA_Sprint | 移动向量和跳跃意图 |
| 弹刀系统 | 输出 IA_Deflect, 输入缓冲 | 弹刀系统消费防御输入 |
| 普攻连段 | 输出 IA_Attack, 输入缓冲 | 连段系统消费攻击输入并检查连段窗口 |
| 闪避/识破 | 输出 IA_Dodge + Direction | 闪避方向用于判定侧闪/后闪/识破 |
| 钩绳 | 输出 IA_GrapplingHook | 仅在钩点可用时响应 |
| 锁定 | 输出 IA_LockOn | 锁定系统管理目标切换 |
| 伤药葫芦 | 输出 IA_UseItem | 触发喝药流程 |

## 公式

### 输入缓冲有效期

```
FrameValid = CurrentFrame - InputFrame <= BufferWindow
```

| 变量 | 类型 | 范围 | 来源 | 说明 |
|------|------|------|------|------|
| CurrentFrame | int | — | GameTime | 当前帧序号 |
| InputFrame | int | — | 缓冲队列 | 输入发生的帧序号 |
| BufferWindow | int | 6-30 | 数据配置 | 缓冲有效帧数 |

**预期输出**: 缓冲窗口内返回 true，超时返回 false

## 边界情况

| 场景 | 预期行为 | 理由 |
|------|---------|------|
| 攻击和防御同时按下 | 防御优先（IA_Deflect 优先级 > IA_Attack） | 只狼战斗哲学：防守优先 |
| 闪避和跳跃同时按下 | 闪避优先 | 战斗中闪避比跳跃更常用 |
| 缓冲队列满 | 丢弃最早的条目（FIFO），推入新条目 | 保持最近输入的响应性 |
| 手柄和键盘同时输入 | EIS 自动处理，优先级：最后触发的设备为准 | 不需要额外处理 |
| 输入设备断开 | 自动切换到剩余设备，不中断游戏 | 手柄没电 → 立刻切键鼠 |
| 暂停时输入 | 仅 IA_Pause 响应，其他输入丢弃且不进入缓冲 | 防止暂停期间误操作 |
| Hold 判定 | Hold 时间 > 0.3s 判定为 Hold，否则为 Tap | 蓄力攻击和普攻的分界 |

## 调优旋钮

| 参数 | 建议默认值 | 安全范围 | 增加的效果 | 减少的效果 |
|------|----------|---------|-----------|-----------|
| BufferSize | 8 | 4-16 | 更多缓冲 → 更宽容 | 更少缓冲 → 更严格 |
| BufferWindow | 12帧 (0.2s) | 6-30 | 更宽容的输入窗口 | 必须更精确输入 |
| HoldThreshold | 0.3s | 0.2-0.5 | 更难触发蓄力 | 更容易误判为蓄力 |
| DeflectPriority | 最高 | — | 不用调 | — |

## 验收标准

- [ ] 所有战斗操作通过 UInputAction 定义，无硬编码按键
- [ ] 键盘鼠标和手柄均可在菜单中重新绑定按键
- [ ] 输入缓冲队列在 PIE 中可观察（通过 `showdebug input` 控制台命令或调试 HUD）
- [ ] 攻击+防御同时按下时，防御优先生效（角色进入防御而非攻击）
- [ ] 暂停期间除 IA_Pause 外所有输入被屏蔽
- [ ] 手柄断开后自动切换到键鼠，游戏不中断
- [ ] 缓冲窗口内的输入被正确消费，窗口外的输入被丢弃
- [ ] Hold/Tap 判定在 0.3s 分界处行为正确
