# 回生系统

> **状态**: 草稿
> **最后更新**: 2026-05-30
> **支撑的支柱**: 死亡与回生

## 概述

回生（Resurrection）是只狼最独特的生存机制——HP 归零后不会立刻死亡，而是获得一次原地复活的机会。回生次数有限（默认 1 次），复活后恢复部分 HP 和架势。忍杀敌人（或满足特定条件）可补充回生节点。回生有短暂冷却，防止连续回生。

## 玩家幻想

"你已经死了"——然后角色单手撑地，挣扎爬起。回生不是免费续关，而是一种战术资源。何时使用回生（还是接受死亡重新开始）是贯穿只狼始终的决策。回生瞬间的爆发感让玩家感觉自己是不可杀死的忍者。

## 详细设计

### 核心规则

1. 狼 HP=0 时进入死亡倒地状态
2. 出现回生提示（"回生" UI 提示 + 按键提示，持续 3s）
3. 玩家按下回生键（或自动触发——根据配置）→ 复活
4. 复活后：HP 恢复到 ResurrectionHP%（如 50%），架势清空
5. 回生次数剩余（初始 1 次），忍杀敌人可补充
6. 回生后短暂硬直（ResurrectionStun 0.5s），期间无敌
7. 如果回生次数为 0 或未在窗口内选择 → 真正死亡（Game Over）

### 回生流程

```
HP=0
├── 进入 DeathKneel 状态
├── 出现回生选择窗口（3s）
├── 玩家选择：
│   ├── 回生（按指定键）：
│   │   ├── 播放回生动画
│   │   ├── HP = MaxHP * ResurrectionHP%
│   │   ├── Posture = MaxPosture * ResurrectionPosture%
│   │   ├── ResurrectionCount -= 1
│   │   ├── 短暂无敌（0.5s）
│   │   ├── 附近敌人播放受惊动画（可选）
│   │   └── 继续战斗
│   └── 不选择（3s 后）：
│       └── 真正死亡 → 重生点 / Game Over
```

### 回生次数管理

| 机制 | 说明 |
|------|------|
| 初始次数 | 1（在休息点重置） |
| 消耗 | 每次回生 -1 |
| 补充 | 忍杀敌人 +1（不超过 MaxResurrections） |
| 充能冷却 | 回生后 30s 内忍杀不充能（防止连杀连续充能） |

### 回生充能规则

```
ResurrectionCharge（充能节点）：
├── 节点状态：Charged / Discharged
├── 死亡时消耗一个 Charged 节点 → Discharged
├── 忍杀时：将 Discharged 节点 → Charged
│   但：如果最后一次回生在 30s 内 → 不充能（冷却中）
└── 在休息点：所有节点强制 Charged
```

### 与其他系统的交互

| 交互系统 | 数据流向 | 说明 |
|----------|---------|------|
| HP & 架势 | 输入 HP=0 / 输出恢复 | 触发回生条件 / 复活后恢复 |
| 忍杀 | 输出充能请求 | 忍杀成功 → 充能回生节点 |
| 动画系统 | 输出回生动效 | 回生/死亡动画 |
| 战斗系统 | 输出无敌状态 | 回生期间短暂无敌 |
| 战斗 HUD | 输出回生节点 UI | 显示回生节点状态 |
| 战斗音效 | 输出回生/死亡音效 | 回生音效 |

## 公式

### 回生恢复

```
NewHP = Clamp(MaxHP * ResurrectionHPRatio, 0, MaxHP)
NewPosture = Clamp(MaxPosture * ResurrectionPostureRatio, 0, MaxPosture)
```

| 变量 | 典型值 |
|------|--------|
| ResurrectionHPRatio | 0.5（恢复50% HP） |
| ResurrectionPostureRatio | 0.0（架势清空） |

### 复活无敌帧

```
InvincibleDuration = 0.5s（回生硬直动画期间）
```

### 充能冷却

```
CanRecharge = (CurrentTime - LastResurrectionTime) > ResurrectionCooldown
ResurrectionCooldown = 30s
```

## 边界情况

| 场景 | 预期行为 | 理由 |
|------|---------|------|
| 回生次数为 0 | 不显示回生提示，直接死亡 | 没有回生资源 |
| 回生窗口内再次死亡 | 不可能——回生窗口期间无敌 | 设计保证 |
| 回生后立刻被攻击 | 复活后 0.5s 无敌帧保护，足够进入弹刀/闪避 | 防止深渊复活（复活即死） |
| Boss 战斗中回生 | Boss 不重置——继续当前阶段和 HP | 回生是战术，不是重置 |
| 回生动画中 Boss 攻击 | Boss 攻击不命中——无敌帧覆盖全程 | 动画中不应被打断 |
| 忍杀充能在冷却 | Discharged 节点不充能 | 防止连续忍杀无限回生 |

## 调优旋钮

| 参数 | 建议默认值 | 安全范围 | 增加的效果 | 减少的效果 |
|------|----------|---------|-----------|-----------|
| MaxResurrections | 1 | 0-3 | 更多容错 | 更接近原版 |
| ResurrectionHPRatio | 0.5 | 0.3-0.7 | 回生后更多HP | 更危险的复活 |
| ResurrectionPostureRatio | 0.0 | 0.0-0.3 | 保留部分架势 | 架势清空 |
| ResurrectionCooldown | 30s | 15-60 | 更长充能冷却 | 更快可充能 |
| ChoiceWindow | 3s | 2-5 | 更长的决策时间 | 更紧迫 |

## 验收标准

- [ ] HP=0 时进入死亡倒地 + 回生选择窗口（3s）
- [ ] 选择回生 → 恢复 50% HP + 架势清空 + 0.5s 无敌
- [ ] 不选择回生（3s 超时）→ 真正死亡
- [ ] 回生次数为 0 时直接死亡，不显示回生提示
- [ ] 忍杀敌人 → 充能 1 个回生节点
- [ ] 回生后 30s 内的忍杀不充能
- [ ] 回生动画期间无敌，Boss 攻击不命中
