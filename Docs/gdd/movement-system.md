# 角色移动系统

> **状态**: 草稿
> **最后更新**: 2026-05-30
> **支撑的支柱**: 垂直机动、精确节奏

## 概述

角色移动系统控制狼的基础移动能力——走/跑/跳/蹲、斜坡/台阶处理，以及战斗状态下的移动限制。基于 UE CharacterMovementComponent 扩展，添加战斗移动约束和钩绳交互。

## 玩家幻想

移动应该流畅而精确——当玩家想走一小步调整弹刀距离，角色就应该只走一小步。战斗中移动受限但不僵硬：锁定状态下角色的步伐是有节奏的滑步，而非僵硬的前后左右。

## 详细设计

### 移动状态

| 状态 | 速度倍率 | 可跳跃 | 可闪避 | 可攻击 | 说明 |
|------|---------|--------|--------|--------|------|
| 待机 (Idle) | 0 | ✓ | ✓ | ✓ | 默认站立 |
| 行走 (Walk) | 0.4× | ✓ | ✓ | ✓ | 轻推摇杆 |
| 奔跑 (Run) | 1.0× | ✓ | ✓ | 需先停止 | 全速移动 |
| 冲刺 (Sprint) | 1.5× | ✓ | ✓ | ✗ | 按住冲刺键 |
| 蹲行 (Crouch) | 0.2× | ✗ | ✓ | ✗ | 潜行用（第一阶段不涉及） |
| 锁定移动 (Locked) | 0.7× | ✓ | ✓ | ✓ | 锁定目标时的侧向步伐 |
| 跳跃中 (InAir) | — | — | ✗ | 仅空中攻击 | 下落/上升 |
| 钩绳中 (Grappling) | — | ✗ | ✗ | ✗ | 钩绳飞行过程 |
| 受击中 (HitStun) | 0 | ✗ | ✗ | ✗ | 被击退/击倒后短暂僵直 |

### 锁定状态下的移动规则

1. 移动输入相对于锁定目标方向（非摇杆绝对方向）
2. 前推摇杆 = 向目标方向移动（靠近）
3. 后推摇杆 = 远离目标
4. 左右 = 绕目标横向移动
5. 移动速度限制为 0.7× RunSpeed
6. 锁定移动时角色始终面朝锁定目标

### 跳跃

1. 起跳：IA_Jump 按下 → 垂直速度 = JumpZVelocity
2. 空中可二段跳（原版只狼无二段跳——根据第一阶段需求待定）
3. 落地硬直：0.1s（极小硬直，不中断操作感）
4. 空中可攻击（跳劈）
5. 空中不可防御/弹刀

### 斜坡/台阶

1. 使用 UE CharacterMovementComponent 的 `CanWalkOffLedges` 和 `MaxStepHeight` 处理
2. 台阶高度 ≤ 45cm 自动走上
3. 斜坡角度 ≤ 45° 可行走，> 45° 滑落

### 钩绳交互

钩绳系统会临时接管移动——在钩绳飞行期间，CharacterMovementComponent 的移动模式切为 `MOVE_Flying`，由钩绳系统直接设置位置。落地后恢复 `MOVE_Walking`。

### 与其他系统的交互

| 交互系统 | 数据流向 | 说明 |
|----------|---------|------|
| 输入系统 | 输入 IA_Move/IA_Jump/IA_Sprint | 移动输入来源 |
| 锁定系统 | 输入锁定目标 | 锁定移动的方向参考 |
| 钩绳系统 | 输出/输入 | 钩绳接管移动，落地后归还 |
| 动画系统 | 输出移动状态 | 动画蓝图根据移动状态选择动画 |
| 战斗系统 | 输入限制 | 攻击/受击时临时约束移动 |

## 公式

### 移动速度计算

```
实际速度 = 基础速度 × 状态倍率 × 方向衰减
方向衰减 = 1.0 (前进) / 0.75 (后退) / 0.85 (侧向)
```

### 锁定移动方向

```
移动方向 = Normalize(摇杆.X × 目标右侧 + 摇杆.Y × 目标前方)
```

## 边界情况

| 场景 | 预期行为 | 理由 |
|------|---------|------|
| 锁定目标死亡 | 自动解除锁定，移动恢复自由模式 | 没有目标就不需要锁定移动 |
| 被击退到悬崖边 | 角色在边缘停止，不会跌落（除非死亡击飞） | 防止非预期的环境击杀 |
| 钩绳中断 | 如果钩绳中途被打断，恢复 MOVE_Walking 并保持当前速度方向 | 不应卡在空中 |
| 攻击中移动输入 | 攻击动画中的根运动（Root Motion）决定位移，摇杆输入不影响位置 | 攻击动作的位移由动画师控制 |
| 防御中移动 | 移动速度降至 0.3× RunSpeed | 真实——举刀防御时移动缓慢 |

## 依赖

| 系统 | 方向 | 依赖性质 |
|------|------|---------|
| 输入系统 | 移动依赖输入 | 移动/跳跃/冲刺指令 |
| 数据配置 | 移动依赖数据配置 | 速度、跳跃高度等参数 |
| 锁定系统 | 移动依赖锁定 | 锁定移动的方向参考 |
| 钩绳系统 | 移动依赖钩绳 | 钩绳接管移动控制 |
| 动画系统 | 依赖移动 | 动画蓝图需要移动状态 |
| 弹刀/防御 | 依赖移动 | 防御时限制移动速度 |

## 调优旋钮

| 参数 | 建议默认值 | 安全范围 | 增加的效果 | 减少的效果 |
|------|----------|---------|-----------|-----------|
| RunSpeed | 600 UE单位/s | 400-900 | 移动更快 → 更灵活 | 更慢 → 更沉重 |
| SprintSpeed | 900 | 600-1200 | 追击更强 | 战略移动受限 |
| LockedMoveSpeed | 420 (0.7×) | 0.5-0.8× | 锁定移速快 → 更灵活 | 更慢 → 更谨慎 |
| JumpZVelocity | 500 | 400-700 | 跳更高 | 跳更矮 |
| MaxStepHeight | 45cm | 30-60 | 更高的台阶可行走 | 更严格的碰撞 |

## 验收标准

- [ ] 所有移动状态（走/跑/冲刺/锁定/蹲）之间的切换平滑无抖动
- [ ] 锁定状态下移动方向以目标为参照（前=靠近目标，左右=绕目标）
- [ ] 跳跃高度和空中时间与 MaxStepHeight/JumpZVelocity 参数一致
- [ ] 攻击动画中的位移完全由 Root Motion 驱动，摇杆不影响
- [ ] 防御状态下移动速度正确降低至 0.3×
- [ ] 被击退到悬崖边缘时角色不跌落
- [ ] 钩绳飞行期间移动被正确接管，落地后正确恢复
