# 闪避/识破系统

> **状态**: 草稿
> **最后更新**: 2026-05-30
> **支撑的支柱**: 精确节奏、刀刃对抗

## 概述

闪避（Dodge）和识破（Mikiri Counter）是只狼防御体系中的机动选项。侧闪和后闪提供位移规避，识破专门应对突刺类危字攻击（踩住敌人武器并造成大量架势伤害），踩踏应对横扫类危字攻击。闪避有短暂的无敌帧（i-Frames），但远少于传统动作游戏——只狼的核心防御手段是弹刀而非翻滚。

## 玩家幻想

精准闪避应该让玩家感觉自己能预见敌人的每一步。识破是只狼最帅的动作之一——看穿突刺，一脚踩住对方武器，瞬间逆转攻守。闪避不是"滚走"而是"侧身躲过"——保持进攻姿态，随时准备弹刀或反击。

## 详细设计

### 闪避类型

| 闪避类型 | 触发 | 距离 | i-Frame | 可取消到 | 说明 |
|----------|------|------|---------|----------|------|
| 后闪 | 无方向 + Dodge | 后撤 250 UE单位 | 6帧 | 攻击/弹刀 | 基础回避 |
| 左闪 | 左 + Dodge | 左侧 200 UE单位 | 6帧 | 攻击/弹刀 | 横向规避 |
| 右闪 | 右 + Dodge | 右侧 200 UE单位 | 6帧 | 攻击/弹刀 | 横向规避 |
| 识破 | 前 + Dodge（对突刺） | 前冲 300，踩踏位移 | — | 攻击 | 克制突刺 |
| 踩踏 | Dodge（对横扫危字） | 跳跃踩踏 | — | 攻击 | 克制横扫 |

### 闪避 i-Frame 规则

1. i-Frame 位于闪避动画的第 1-6 帧（0.1s @60fps）
2. i-Frame 期间 Hurtbox 对 ECC_SKAttack 通道无响应
3. i-Frame 结束后 Hurtbox 立即恢复
4. **没有闪避链**：不能连续闪避（与魂系列不同），每次闪避后有短暂硬直（0.1s）

### 识破判定

```
1. 玩家面朝锁定目标
2. 向前推摇杆 + 按下 Dodge
3. 检查：锁定目标是否在中执行 FrameOf(PerilousAttack_Thrust) 动画？
   ├── YES → 识破成功
   │         ├── 玩家自动冲向前 → 踩住武器动画
   │         ├── 敌人架势 += MikiriPostureDamage（大量）
   │         ├── 敌人进入 MikiriStagger（0.3s）
   │         └── 玩家可立即攻击
   └── NO → 正常前闪（普通闪避，躲到敌人背后）
```

### 识破检测窗口

识破判定的检测范围：
- 距离：前冲 300 UE 单位内
- 角度：玩家朝向与目标方向 ±30°
- 时机：突刺攻击的 ActiveFrames 期间

### 踩踏判定

```
1. 锁定目标执行危字•横扫攻击
2. 玩家按下 Dodge（方向不限）
3. 检查：目标是否是 PerilousAttack_Sweep？
   ├── YES → 踩踏
   │         ├── 玩家起跳 → 踩在敌人身上
   │         ├── 敌人架势 += StompPostureDamage
   │         └── 玩家可空中攻击或落地
   └── NO + 横扫仍命中 → 受击
```

### 闪避惩罚

- 闪避动画结束后 0.1s 不可再次闪避（防止连闪）
- 闪避中不可防御（i-Frame 结束后到闪避结束前是脆弱窗口）
- 后闪距离较短——不应让玩家轻易脱离战斗

### 与其他系统的交互

| 交互系统 | 数据流向 | 说明 |
|----------|---------|------|
| 输入系统 | 输入 IA_Dodge + Direction | 闪避方向和时机 |
| 锁定系统 | 输入锁定目标 | 识破/踩踏需要目标 |
| 碰撞检测 | 闪避时临时禁用 Hurtbox | i-Frame 实现 |
| HP & 架势 | 输出架势伤害 | 识破/踩踏对敌架势伤害 |
| 动画系统 | 输出闪避/识破/踩踏动作 | 触发动效 |
| 危字攻击 | 输入危字类型 | 判定识破 vs 踩踏 |
| 伤害计算 | 闪避时免伤 | i-Frame 期间伤害 = 0 |

## 公式

### i-Frame 判定

```
bInIFrame = DodgeElapsedFrames >= 1 && DodgeElapsedFrames <= 6
```

### 识破伤害

```
MikiriPostureDamage = BasePostureDamage * 1.5  // 识破的架势伤害比普攻高 50%
StompPostureDamage = BasePostureDamage * 1.0   // 踩踏等于普攻架势伤害
```

## 边界情况

| 场景 | 预期行为 | 理由 |
|------|---------|------|
| 非锁定状态下识破 | 不可识破——只有锁定目标时才能向前识破 | 不锁定不知道谁是目标 |
| 识破窗口外前闪 | 普通前闪——躲到敌人背后（近距离可能躲掉攻击但不产生识破效果） | 前闪仍有位移价值 |
| 同时突刺+横扫 | 两者不可同时发生——由 Boss AI 保证 | AI 设计层面约束 |
| 闪避到墙边 | 闪避位移被碰撞截断，i-Frame 时间不变 | 不应穿墙 |
| 被击晕时闪避 | 不可闪避——受击动画优先 | 硬直中无法行动 |
| 无危字的突刺 | 仍可被识破判定——危字只是 UI 提示，不是必要条件 | 高级玩法：看动作而非看危字 |

## 调优旋钮

| 参数 | 建议默认值 | 安全范围 | 增加的效果 | 减少的效果 |
|------|----------|---------|-----------|-----------|
| DodgeIFrames | 6帧 (0.1s) | 4-10 | 闪避更宽容 | 闪避更严格 |
| DodgeDistance | 200-250 UE单位 | 150-350 | 闪得更远 | 闪得更近 |
| DodgeCooldown | 0.1s | 0-0.3 | 更长冷却 | 可连闪 |
| MikiriPostureDamageMultiplier | 1.5× | 1.2-2.0 | 识破更强力 | 识破只是对策 |
| MikiriLungeDistance | 300 UE单位 | 200-400 | 更远识破 | 更近识破 |

## 验收标准

- [ ] 锁定目标 + 前闪 + 突刺 → 识破成功（踩武器动画 + 架势伤害）
- [ ] 锁定目标 + 闪避 + 横扫 → 踩踏成功
- [ ] 闪避 i-Frame 第 1-6 帧期间攻击判定不命中
- [ ] i-Frame 结束后（第 7 帧起）可被正常命中
- [ ] 非锁定状态下前闪不触发识破（普通前闪位移）
- [ ] 闪避结束后 0.1s 内不可再次闪避
- [ ] 闪避期间不可防御
- [ ] 识破成功后敌人产生 MikiriStagger（0.3s 硬直）
