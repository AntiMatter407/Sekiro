# 只狼战斗系统迁移 — 游戏概念文档

## 概述

将《Sekiro: Shadows Die Twice》的核心战斗机制完整复刻到 Unreal Engine 5.2。
第一阶段目标：实现主角「狼」与一个 Boss 的完整战斗闭环。

## 游戏支柱

### 刀刃对抗
核心不是削减 HP，而是打崩对方架势。弹刀是主要交互语言，敌我刀刃碰撞构成战斗的心跳。

### 精确节奏
每个敌人有独特的攻击节奏，玩家需要读取→反应→执行。不存在等级压制——理解敌人节奏是唯一出路。

### 垂直机动
钩绳让战斗空间从平面扩展到立体，提供脱离、绕后、高处突袭等战术选择。

### 死亡与回生
回生机制提供有限不死，带来策略深度——何时回生是关键决策。

## 核心循环

```
探索/移动 → 遭遇敌人 → 攻防博弈（弹刀/闪避/反击）
    → 架势崩坏 → 忍杀处决 → 继续探索
                    ↘ 死亡 → 回生 → 继续战斗
```

## 第一阶段范围

- **可玩角色**：狼（Wolf）
- **敌人**：1 个完整 Boss
- **战斗系统**：普攻、弹刀、闪避、识破、踩踏、架势/HP、忍杀、危字攻击
- **生存系统**：回生、伤药葫芦
- **移动系统**：走/跑/跳、钩绳、锁定
- **UI**：HP 条、架势条、锁定标记、危字提示

## 引擎与技术

- **引擎**：Unreal Engine 5.2
- **语言**：C++（核心），Blueprint + Lua（脚本/配置）
- **战斗框架**：Gameplay Ability System (GAS) 或自定义轻量方案（待 ADR 决策）
- **动画**：UE Animation Blueprint + Montage
- **物理/碰撞**：UE 内置物理 + 自定义攻击盒系统

## 不计入第一阶段

- 义手忍具（义手、爆竹、手里剑等）
- 技能树/流派招式
- 多敌人 AI
- 潜行/暗杀
- 地图/关卡设计
- 剧情/对话系统
