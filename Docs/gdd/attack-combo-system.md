# 普攻连段系统

> **状态**: 草稿
> **最后更新**: 2026-05-30
> **支撑的支柱**: 刀刃对抗、精确节奏

## 概述

普攻连段系统管理狼的基础攻击——轻击连段（通常 3-4 段）和蓄力突刺。攻击通过输入缓冲队列识别，连段通过 CancelWindow 衔接。每段攻击的伤害、架势伤害、攻击盒大小和帧数据由数据配置定义。系统支持攻击取消（切换到弹刀/闪避）和连段窗口（在取消窗口内再次攻击进入下一段）。

## 玩家幻想

每一刀都应有斩击的重量感——挥刀的快慢节奏、命中时的停顿、被弹刀时的反馈。连段是流畅的但不应该鼓励无脑连按：如果第一刀被弹刀了，连按第二刀应该硬直而不是继续连段。

## 详细设计

### 攻击类型

| 类型 | 输入 | 说明 |
|------|------|------|
| 轻击连段 (Combo) | Tap IA_Attack | 连续轻击 3-4 段，每段有 CancelWindow |
| 蓄力突刺 (Thrust) | Hold IA_Attack > 0.3s | 蓄力后释放 → 前冲刺击 |
| 跳劈 (Jump Attack) | Jump 中 IA_Attack | 空中向下斩击 |
| 弹刀反击 (Deflect Counter) | 弹刀成功 → IA_Attack | 弹刀后立即攻击（CancelWindow 提前开启） |
| 闪避追击 (Dodge Attack) | 闪避后 IA_Attack | 闪避后快速突进攻击 |

### 连段状态机

```
Idle/Defense
├── IA_Attack Tap → Combo_1
│   ├── CancelWindow内 IA_Attack → Combo_2
│   │   ├── CancelWindow内 IA_Attack → Combo_3
│   │   │   ├── CancelWindow内 IA_Attack → Combo_4 (Final)
│   │   │   └── CancelWindow过期 → 回 Idle
│   │   └── CancelWindow过期 → 回 Idle
│   └── CancelWindow过期 → 回 Idle
├── IA_Attack Hold > 0.3s → Thrust_Charge → IA_Attack Release → Thrust_Attack
└── 被弹刀 → Stagger（连段中断，不可继续）
```

### 输入缓冲与连段

1. 攻击输入进入缓冲队列（输入系统管理）
2. 在 CancelWindow 内检查缓冲队列是否有攻击输入
3. 如果有 → 进入下一段连段
4. 如果没有 → 连段在 CancelWindow 结束后回到 Idle
5. **被弹刀后缓冲清除**：如果当前攻击被弹刀，清除缓冲中的后续攻击输入——惩罚无脑连按

### CancelWindow（攻击取消规则）

| 当前动作 | 可取消到 | 窗口 |
|----------|---------|------|
| Combo_1 | Combo_2 | 第 18-24 帧 |
| Combo_1 | Deflect | 第 12-24 帧 |
| Combo_1 | Dodge | 第 12-20 帧 |
| Combo_2 | Combo_3 | 第 20-26 帧 |
| Combo_2 | Deflect | 第 14-26 帧 |
| Combo_2 | Dodge | 第 14-22 帧 |
| Combo_3 | Combo_4 | 第 22-30 帧 |
| Combo_3 | Deflect | 第 16-30 帧 |
| Combo_4 (Final) | Deflect | 第 18-35 帧 |
| Combo_4 (Final) | — | 不可取消到攻击（已是最后一段） |

### 被弹刀后的行为

```
我方攻击 → 被对方弹刀成功
→ 我方进入 Micro-Stagger (0.15s)
→ 我方输入缓冲中的攻击指令已被清除
→ Micro-Stagger 结束后可以弹刀/闪避/重新攻击
```

这保证了弹刀方（无论是玩家还是 Boss）获得战术优势。

### 攻击方向

锁定状态下，攻击自动面朝锁定目标。非锁定状态下，攻击方向 = 摇杆方向（或默认角色朝向）。

### 与其他系统的交互

| 交互系统 | 数据流向 | 说明 |
|----------|---------|------|
| 输入系统 | 输入 IA_Attack（Tap/Hold）+ 缓冲查询 | 攻击触发和连段衔接 |
| 碰撞检测 | 输出 AnimNotify → 攻击盒 | 攻击盒由动画通知驱动 |
| 动画系统 | 输出攻击动作类型 → AnimBP | 驱动连段 Montage |
| 伤害计算 | 输出攻击命中 | 提供 AttackID 和命中数据 |
| 弹刀系统 | 输入被弹刀事件 | 被弹刀 → 连段中断 |
| HP & 架势 | 输出架势伤害 | 攻击的架势伤害值 |
| 数据配置 | 依赖攻击参数 | 帧数据、伤害、攻击盒尺寸 |
| 锁定系统 | 依赖锁定目标 | 攻击方向 |

## 公式

### 连段窗口判定

```
bInComboWindow = CurrentFrame >= CancelWindowStart && CurrentFrame <= CancelWindowEnd
               && InputBuffer.Has(IA_Attack)
               && !bWasDeflected  // 未被弹刀
```

### 蓄力阈值

```
bThrust = HoldDuration(IA_Attack) >= HoldThreshold (0.3s)
```

## 边界情况

| 场景 | 预期行为 | 理由 |
|------|---------|------|
| 取消窗口内按下攻击+弹刀 | 弹刀优先 | 防御优先原则 |
| 被弹刀后连按攻击 | 连段中断，缓冲清除，Micro-Stagger 后需要重新输入 | 惩罚无脑连按 |
| 连段中锁定目标死亡 | 当前攻击结束后自动解锁，连段中断 | 没有目标就没有连段方向 |
| 连段中目标闪现身后 | 当前段锁定方向不变（动画朝向锁定），下一段重新获取目标位置 | 防止动画瞬切 |
| 蓄力中被打断 | 蓄力取消，不触发突刺 | 受击优先 |

## 依赖

| 系统 | 方向 | 依赖性质 |
|------|------|---------|
| 输入系统 | 依赖输入 | 攻击按键 + 缓冲 |
| 动画系统 | 依赖动画 | Montage + CancelWindow Notify |
| 碰撞检测 | 依赖碰撞 | 攻击盒命中判定 |
| 弹刀系统 | 输入被弹刀 | 被弹刀 → 中断 |
| 伤害计算 | 输出伤害 | AttackID → 伤害值 |
| 锁定系统 | 依赖锁定 | 攻击朝向 |
| 数据配置 | 依赖数据配置 | FSKAttackData |

## 调优旋钮

| 参数 | 建议默认值 | 安全范围 | 增加的效果 | 减少的效果 |
|------|----------|---------|-----------|-----------|
| CancelWindowSize (每段) | 6-12帧 | 4-16 | 连段更容易衔接 | 连段需要更精确 |
| ComboCount | 4 | 3-5 | 更长连段 | 更短连段 |
| HoldThreshold | 0.3s | 0.2-0.5 | 更难蓄力 | 更容易误触蓄力 |
| MicroStagger (被弹刀) | 0.15s | 0.1-0.25 | 被弹刀后硬直更久 | 更快恢复 |
| Combo_Damage（每段递增） | 1.0×/1.1×/1.2×/1.5× | — | 鼓励完成连段 | 每段相同价值 |

## 验收标准

- [ ] Combo 1→2→3→4 在 CancelWindow 内连续按攻击时正确完成
- [ ] CancelWindow 外按键不触发下一段连段
- [ ] 被弹刀后缓冲清除，不可继续连段
- [ ] 蓄力 > 0.3s 后释放 → 突刺攻击
- [ ] 蓄力 < 0.3s 后释放 → 普通第一段攻击
- [ ] 弹刀反击（弹刀成功→立即攻击）CancelWindow 正确提前开启
- [ ] 连段中锁定目标死亡 → 连段在当前段结束后中断
- [ ] 锁定状态下所有攻击自动面朝目标
