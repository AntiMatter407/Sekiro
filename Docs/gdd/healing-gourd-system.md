# 伤药葫芦系统

> **状态**: 草稿
> **最后更新**: 2026-05-30
> **支撑的支柱**: 死亡与回生

## 概述

伤药葫芦（Healing Gourd）是只狼的主要恢复手段。使用次数有限（默认 1-3 次，可在休息点补充），每次使用恢复一定比例的 HP。喝药动作有硬直（不可取消），玩家需在战斗中寻找安全时机。原版只狼中喝药可被闪避取消——第一阶段保留此特性。

## 玩家幻想

在 Boss 连段间隙后撤一步，迅速喝一口葫芦——HP 绿条上涨的瞬间带来了喘息。但这种喘息是有代价的：喝药硬直期间如果被抓住就是白喝。寻找喝药时机本身就是战斗的一部分。

## 详细设计

### 核心规则

1. 葫芦使用次数（MaxCharges）在数据配置中定义
2. 每次使用 IA_UseItem → 播放喝药动画 + HP 恢复
3. 喝药动画可被闪避取消（原版设定）——但取消后不恢复 HP
4. 喝药不可被弹刀取消
5. 使用次数在休息点重置为 MaxCharges（第一阶段默认可通过在固定点触发）
6. HP 恢复量 = HealAmount（固定值，非百分比）

### 使用流程

```
1. 按 IA_UseItem
2. 检查条件：
   ├── Charges > 0
   ├── 可行动状态（非受击/死亡中）
   └── 不在其他无法取消的动作中（如被弹刀硬直中）
3. 满足 → 开始喝药动画
   ├── 动画时长 HealDuration
   ├── 在 HealWindow 时间点（如 0.4s 后）恢复 HP
   └── 动画结束前可被闪避取消（但取消后 HP 不恢复）
4. Charges -= 1
```

### 硬直与取消规则

| 动作 | 能否取消喝药 | 说明 |
|------|------------|------|
| 闪避 | ✓ | 取消后 HP 不恢复，葫芦次数照扣 |
| 弹刀/防御 | ✗ | 喝药中不可防御 |
| 攻击 | ✗ | 喝药中不可攻击 |
| 跳跃 | ✗ | 喝药中不可跳跃 |

### 与其他系统的交互

| 交互系统 | 数据流向 | 说明 |
|----------|---------|------|
| 输入系统 | 输入 IA_UseItem | 喝药触发 |
| HP & 架势 | 输出 HealAmount | HP 恢复 |
| 动画系统 | 输出喝药 Montage | 喝药动画 |
| 数据配置 | 依赖配置 | 次数、回血量、时长 |
| 战斗 HUD | 输出剩余次数 | HUD 葫芦图标 |

## 公式

### HP 恢复

```
NewHP = Min(CurrentHP + HealAmount, MaxHP)
```

| 变量 | 典型值 |
|------|--------|
| HealAmount | 30（约 30% MaxHP，如果 MaxHP=100） |
| MaxCharges | 3 |
| HealDuration | 1.2s |
| HealWindow | 0.4s |

### 使用次数

```
Charges -= 1（喝药动作开始即扣除，即使被取消）
if Charges == 0 → UI 显示空葫芦
```

## 边界情况

| 场景 | 预期行为 | 理由 |
|------|---------|------|
| HP 已满时喝药 | 允许喝药但 HP 不变，次数照扣 | 不阻止玩家犯错 |
| 次数为 0 时喝药 | 不触发——UI 已显示空葫芦 | 没有资源可用 |
| 喝药中被打断（非取消） | 如果受击 → 喝药中断，HP 未恢复，次数照扣 | 惩罚错误时机 |
| 喝药用闪避取消 | HP 不恢复，次数照扣 | 取消是逃生手段，不保留资源 |
| 连续喝药 | 不可以——喝药动画结束后 0.2s 才可再次喝药 | 防止快速连按 |

## 依赖

| 系统 | 方向 | 依赖性质 |
|------|------|---------|
| 输入系统 | 依赖输入 | IA_UseItem |
| HP & 架势 | 输出恢复 | HP 恢复 |
| 动画系统 | 依赖动画 | 喝药 Montage |
| 闪避 | 依赖闪避 | 取消喝药 |
| 战斗 HUD | 输出状态 | 剩余次数显示 |
| 数据配置 | 依赖数据配置 | FSKHealingGourdConfig |

## 调优旋钮

| 参数 | 建议默认值 | 安全范围 | 增加的效果 | 减少的效果 |
|------|----------|---------|-----------|-----------|
| MaxCharges | 3 | 1-5 | 更多续航 | 更少容错 |
| HealAmount | 30 | 20-50 | 每次回更多 | 每次回更少 |
| HealDuration | 1.2s | 0.8-1.5 | 更长硬直 | 更快喝药 |
| HealWindow | 0.4s | 0.2-0.6 | 更晚回血 | 更早回血 |
| HealCooldown | 0.2s | 0-0.5 | 更长的喝药间隔 | 可连续喝 |

## 验收标准

- [ ] 按 IA_UseItem → 播放喝药动画 → 在 HealWindow 时恢复 HP
- [ ] 喝药用闪避取消 → HP 不恢复，次数照扣
- [ ] 次数为 0 时不触发喝药
- [ ] HP 已满时喝药 → 次数照扣，HP 不变
- [ ] 喝药中被攻击 → 喝药中断，次数照扣
- [ ] HUD 正确显示剩余葫芦次数
