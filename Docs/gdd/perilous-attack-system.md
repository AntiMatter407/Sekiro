# 危字攻击系统

> **状态**: 草稿
> **最后更新**: 2026-05-30
> **支撑的支柱**: 精确节奏、刀刃对抗

## 概述

危字攻击（Perilous Attack）是只狼的特殊攻击类型——敌人发出不可格挡但可被特定动作克制的攻击。危字分三类：突刺（识破）、横扫（踩踏/跳跃）、投技（闪避）。危字攻击在触发时显示"危"字 UI 警示，给玩家反应时间。此系统管理危字攻击的判定、分类和 UI 提示。

## 玩家幻想

"危"字闪现的瞬间，玩家的注意力被压缩到极致——判断红字 → 识别攻击类型 → 选择正确应对。成功应对后带来的逆转快感是只狼最上瘾的时刻。

## 详细设计

### 危字攻击类型

| 类型 | 标志 | 可弹刀 | 可格挡 | 对策 | 失误后果 |
|------|------|--------|--------|------|---------|
| 突刺 (Thrust) | 红色直刺动画 | ✗ | ✗ | 识破 | 全额伤害 |
| 横扫 (Sweep) | 低扫动画 | ✗ | ✗ | 踩踏/跳跃 | 全额伤害 |
| 投技 (Grab) | 伸手抓取动画 | ✗ | ✗ | 闪避 | 高额伤害 + 投技演出 |

### 危字 UI 警示流程

```
1. 敌人开始危字攻击动画（AnimNotify: PerilousStart）
2. "危"字在敌人头顶/屏幕上方出现（红色，放大动画）
3. 玩家有 0.3-0.5s 反应时间（危字出现到攻击判定帧）
4. 玩家执行对策：
   ├── 正确 → 识破/踩踏/闪避成功
   └── 错误/无动作 → 被命中
5. 危字消失（AnimNotify: PerilousEnd 或命中后）
```

### 危字 UI 参数

| 参数 | 值 |
|------|-----|
| 出现动画 | 0.15s 放大 + 透明度 0 → 1 |
| 颜色 | 红色（RGB: 255, 30, 30） |
| 字号 | 大号（占屏幕 5%） |
| 位置 | 屏幕上方 20% 居中 |
| 音效 | 危字专用警示音 |
| 持续时间 | 从 AnimNotify 开始到判定帧后 0.2s |

### 判定规则

```
突刺：
  └── 识破（前闪）→ 成功 → 踩住武器 + 架势伤害
  └── 闪避（侧/后）→ 可能躲掉（i-Frame）但不产生反击
  └── 弹刀/格挡 → 失败 → 被命中

横扫：
  └── 踩踏（闪避键）→ 成功 → 跳跃踩踏 + 架势伤害
  └── 跳跃 → 可能躲掉（空中不判定横扫）+ 可空中攻击
  └── 弹刀/格挡/识破 → 失败 → 被命中

投技：
  └── 闪避（i-Frame）→ 成功 → 完全躲避
  └── 弹刀/格挡/识破 → 失败 → 被投技抓住
```

### 与其他系统的交互

| 交互系统 | 数据流向 | 说明 |
|----------|---------|------|
| 动画系统 | 输入 AnimNotify | 危字动画标记 |
| 碰撞检测 | 输出特殊攻击盒 | 危字攻击盒类型标记 |
| 闪避/识破 | 输入危字类型 | 识破/踩踏判定 |
| 弹刀系统 | 输出弹刀无效 | 危字不可弹刀 |
| 战斗 HUD | 输出危字提示 | UI 显示危字 |
| 战斗音效 | 输出危字音效 | 警示音 |
| 伤害计算 | 输出伤害 | 被危字命中 = 全额高伤害 |
| 数据配置 | 依赖 PerilousType | FSKAttackData.IsPerilous |

## 公式

### 危字反应窗口

```
ReactionWindow = ActiveFrames + PerilousWarningFrames
PerilousWarningFrames = 18-30（0.3-0.5s）
```

### 危字攻击伤害倍率

```
PerilousDamageMultiplier = 1.5×（危字攻击的 HP 和架势伤害比普通攻击高 50%）
```

## 边界情况

| 场景 | 预期行为 | 理由 |
|------|---------|------|
| 危字 + 普通攻击同时 | 危字判定优先——如果识破/踩踏判定成功，普通攻击也被对策 | 对策动作应覆盖两类攻击 |
| 危字提示后敌人被打断 | 危字消失——危字是动画驱动的 | 动作被打断则威胁消失 |
| 两位敌人同时危字 | 各显示各的危字——UI 取距离最近的危字放大显示 | 信息不冲突 |
| 危字在视线外 | 仍显示危字 UI（屏幕边缘箭头指示方向） | 不应因视角问题吃亏 |
| 危字攻击被闪避 i-Frame 躲过 | 危字攻击命中判定失败 → 正常空挥，无额外惩罚 | i-Frame 是通用防御机制 |

## 依赖

| 系统 | 方向 | 依赖性质 |
|------|------|---------|
| 动画系统 | 依赖动画 Notify | 危字开始/结束标记 |
| 闪避/识破 | 依赖识破/踩踏 | 危字对策判定 |
| 弹刀系统 | 输出弹刀无效 | 危字不可弹刀 |
| 战斗 HUD | 依赖 HUD | 危字 UI 显示 |
| 战斗音效 | 输出音效 | 危字警示音 |
| 伤害计算 | 输出伤害 | 危字命中伤害 |
| 数据配置 | 依赖 FSKAttackData | PerilousType |

## 调优旋钮

| 参数 | 建议默认值 | 安全范围 | 增加的效果 | 减少的效果 |
|------|----------|---------|-----------|-----------|
| PerilousWarningFrames | 24 (0.4s) | 12-36 | 更长的反应时间 | 更紧迫的反应窗口 |
| PerilousDamageMultiplier | 1.5× | 1.2-2.0 | 危字更致命 | 危字仅战术区别 |
| PerilousUIScale | 1.0 | 0.8-1.5 | 更大的危字 | 更小的危字 |

## 验收标准

- [ ] 突刺 → 识破成功（不可弹刀/格挡）
- [ ] 横扫 → 踩踏成功（不可弹刀/格挡/识破）
- [ ] 投技 → 仅可闪避（不可弹刀/格挡/识破）
- [ ] 危字提示在攻击判定前 0.3-0.5s 出现
- [ ] 危字动画被打断时 UI 标记正确消失
- [ ] 危字攻击命中时伤害倍率 1.5×
- [ ] 两个敌人同时危字时 UI 不重叠混淆
