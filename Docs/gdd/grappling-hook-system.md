# 钩绳系统

> **状态**: 草稿
> **最后更新**: 2026-05-30
> **支撑的支柱**: 垂直机动

## 概述

钩绳（Grappling Hook）是只狼独特的垂直移动工具。玩家可以看到特定的钩绳锚点（Grapple Point），按下钩绳键后快速飞向锚点位置。战斗中钩绳可以用于脱离、高处突袭和战术位移。第一阶段范围较小——主要用于 Boss 场景的少数预设锚点。

## 玩家幻想

按下钩绳键的瞬间，角色如忍者般迅速飞向高点——带来一种自由感和空间掌控感。钩绳应该是可信的物理移动，而非传送——角色沿着一条弧线飞行，有速度和加速度。

## 详细设计

### 核心规则

1. 钩绳锚点（Grapple Points）是场景中的固定位置（Socket），在 Content 中预置
2. 玩家接近锚点且在有效范围内时，锚点显示绿色 UI 提示
3. 按下 IA_GrapplingHook → 角色飞向最近的（或屏幕中心指向的）有效锚点
4. 飞行过程中移动模式切为 `MOVE_Flying`，由钩绳系统直接控制位置
5. 落地后恢复 `MOVE_Walking`
6. 飞行中不可攻击/防御/闪避，但到达后可以立即空中攻击（跳劈）

### 锚点有效性判定

```
GrapplePoint 有效条件（全部满足）：
1. 距离 ≤ MaxGrappleRange（默认 2000 UE单位）
2. 在玩家视野内（屏幕投影 + 遮挡检测）
3. 锚点未被其他实体占据
4. 玩家未处于禁止钩绳的状态（受击中/死亡/忍杀中）
```

### 锚点选择

当多个锚点同时有效时：
1. 选择屏幕中心最近的锚点（角度权重 0.7，距离权重 0.3）
2. 如果没有直接瞄准任何锚点，选择距离最近的有效锚点

### 飞行路径

```
1. 计算起点（角色位置）→ 终点（锚点位置 + 偏移）
2. 飞行路径 = 贝塞尔曲线（起点、锚点前上方控制点、终点）
3. 飞行时间 = Max(0.3s, Distance / GrappleSpeed)
4. 飞行中角色朝向 = 切线方向
5. 加速度/减速度：起飞加速 0.1s → 匀速 → 落地减速 0.1s
```

### 状态限制

| 状态 | 能否使用钩绳 |
|------|-------------|
| Idle/Walk/Run | ✓ |
| 跳跃中 | ✓ |
| 锁定移动中 | ✓ |
| 攻击中 | ✗ |
| 防御中 | ✗ |
| 闪避中 | ✗ |
| 受击中 | ✗ |
| 忍杀中 | ✗ |
| 喝药中 | ✗ |

### 钩绳取消

- 飞行中不可手动取消（到终点为止）
- 飞行中被攻击 → 击落（中断飞行，进入受击动画）

### 与其他系统的交互

| 交互系统 | 数据流向 | 说明 |
|----------|---------|------|
| 输入系统 | 输入 IA_GrapplingHook | 钩绳触发 |
| 移动系统 | 输出飞行控制 | 临时接管移动模式 |
| 动画系统 | 输出飞行动画 | 钩绳飞行动画 |
| 战斗系统 | 输入限制 | 钩绳期间暂停战斗状态 |
| 锁定系统 | 输出锚点位置 | 可能优先选择锁定目标附近的锚点 |

## 公式

### 飞行速度

```
Speed(t) = Lerp(0, GrappleSpeed, t/0.1)  // 前 0.1s 加速
          (匀速 0.1s 到 TotalTime-0.1s)
          Lerp(GrappleSpeed, 0, (t-(TotalTime-0.1))/0.1)  // 最后 0.1s 减速
GrappleSpeed = 2000 UE单位/s
```

### 飞行总时间

```
TotalTime = Max(0.3s, Distance / GrappleSpeed)
```

### 锚点选择打分

```
Score = 0.7 * (1 - AngleToCenter / MaxAngle) + 0.3 * (1 - Distance / MaxRange)
```

## 边界情况

| 场景 | 预期行为 | 理由 |
|------|---------|------|
| 飞行中被攻击 | 击落，进入受击动画 | 钩绳不是无敌帧 |
| 锚点在飞行中消失 | 飞到目标点（锚点消失前的世界坐标）并落地 | 不应卡在空中 |
| 锚点被其他角色占据 | 锚点暂时无效（显示灰色），等腾空后恢复 | 两个角色不应叠加 |
| 锚点超出范围但在视野内 | 显示灰色提示（让玩家知道有锚点但太远） | UX 友好 |
| 无有效锚点按钩绳 | 不触发任何动作，可选播放"无法使用"音效 | 不应无效反馈 |
| 贴墙状态下钩绳 | 不触发——需要至少 100 UE单位的最小飞行距离 | 防止贴墙微挪 |

## 依赖

| 系统 | 方向 | 依赖性质 |
|------|------|---------|
| 输入系统 | 依赖输入 | IA_GrapplingHook |
| 移动系统 | 依赖移动 | 接管移动模式 |
| 动画系统 | 依赖动画 | 飞行/钩绳动画 |
| 数据配置 | 依赖数据配置 | 钩绳速度、最大距离 |
| 场景系统 | 依赖场景 | 锚点 Actor 放置 |

## 调优旋钮

| 参数 | 建议默认值 | 安全范围 | 增加的效果 | 减少的效果 |
|------|----------|---------|-----------|-----------|
| MaxGrappleRange | 2000 UE单位 | 1000-4000 | 更远钩绳 | 更短钩绳 |
| GrappleSpeed | 2000 UE单位/s | 1200-3000 | 飞得更快 | 飞得更慢 |
| MinGrappleDistance | 100 | 50-200 | 最小飞行距离更长 | 可贴墙钩 |
| AccelerationTime | 0.1s | 0.05-0.2 | 起飞更慢 | 起飞更快 |

## 验收标准

- [ ] 靠近有效锚点时显示绿色 UI 提示
- [ ] 按下钩绳键后角色沿曲线飞向锚点
- [ ] 飞行中不可攻击/防御/闪避
- [ ] 落地后立即可以行动（包括空中攻击）
- [ ] 飞行中被攻击 → 击落 + 受击动画
- [ ] 超出范围的锚点显示为灰色
- [ ] 无有效锚点时按键不触发任何移动
- [ ] 攻击/防御/受击中不响应钩绳按键
