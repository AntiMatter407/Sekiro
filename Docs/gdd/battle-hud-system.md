# 战斗 HUD 系统

> **状态**: 草稿
> **最后更新**: 2026-05-30
> **支撑的支柱**: 精确节奏、刀刃对抗

## 概述

战斗 HUD（Battle HUD）系统负责战斗中所有 UI 元素的显示和更新——玩家 HP/架势条、Boss HP/架势条、锁定标记、危字提示、葫芦剩余次数、回生节点状态和忍杀红点提示。HUD 是玩家在战斗中获取状态的唯一界面，必须清晰、快速响应且不遮挡核心战斗区域。

## 玩家幻想

战斗 HUD 是玩家的"忍者感知"——用最少的 UI 传达最关键的信息。HP 和架势条的位置让玩家无需移开视线就能感知状态，"危"字的出现是瞬间的警告反射，忍杀红点是胜利在望的信号。

## 详细设计

### 核心规则

1. HUD 元素通过事件/委托驱动更新，不每帧轮询
2. 所有 HUD 元素注册到对应的数据源（HP 系统、架势系统、锁定系统等）
3. HUD 更新在 UI 线程执行，不阻塞游戏线程
4. Boss HP 条仅在锁定 Boss 或 Boss 在战斗状态时显示
5. 非战斗状态时战斗 HUD 元素隐藏

### HUD 布局

```
屏幕上方居中：
  [危] ← 危字提示（需要时显示）

屏幕左上：
  [葫芦图标 × 3] ← 剩余次数

屏幕左下：
  [回生节点] ← 回生状态指示

屏幕左下方：
  ╔═══════════════════╗
  ║ [玩家 HP 条]      ║  ← 绿色 HP 条
  ╚═══════════════════╝
  ╔═══════════════════╗
  ║ [玩家架势条]      ║  ← 橙色架势条
  ╚═══════════════════╝

屏幕上方(锁定 Boss 时)：
  ╔══════════ [Boss 名称] ══════════╗
  ║ [Boss HP 条 ● ● ]              ║  ← Boss HP 条 + 忍杀节点
  ╚═════════════════════════════════╝
  ╔═════════════════════════════════╝
  ║ [Boss 架势条]                  ║  ← Boss 架势条
  ╚═════════════════════════════════╝

屏幕中心(目标身上)：
  [锁定标记] ← 锁定目标的白色圆点

屏幕中心(可忍杀目标身上)：
  [红色忍杀标记] ← 忍杀提示
```

### HUD 元素详细规格

| 元素 | 位置 | 数据源 | 更新方式 | 动画 |
|------|------|--------|---------|------|
| HP 条 | 左下 | HP 系统 OnHPChanged | 事件驱动 | 血量减少时白色残影延迟消失 |
| 架势条 | 左下（HP 条下方） | 架势系统 OnPostureChanged | 事件驱动 | 架势充满时红色闪烁 |
| Boss HP 条 | 上方居中 | Boss HP 系统 | 事件驱动 | 忍杀扣除节点时节点破碎动画 |
| Boss 架势条 | 上方居中（HP 条下方） | Boss 架势系统 | 事件驱动 | 充满时红色脉冲 |
| Boss 名称 | 上方居中（HP 条上方） | Boss 数据 | 一次性设置 | 淡入 |
| 锁定标记 | 跟随目标 | 锁定系统 | 每帧更新位置 | 无，跟随吸附 |
| 危字提示 | 上方居中 | 危字系统 | 事件驱动 | 0.15s 放大 + 透明度 0→1 |
| 葫芦次数 | 左上 | 伤药葫芦系统 | OnChargesChanged | 使用后图标变暗 |
| 回生节点 | 左下（HP上方） | 回生系统 | OnResurrectionChanged | 消耗时节点熄灭 |
| 忍杀标记 | 跟随目标 | 忍杀系统 | 事件驱动 | 出现时放大脉冲 |

### HP 条残影效果

HP 条减少时，先显示一段白色残影延迟消失，模拟只狼原版的"后确认伤害"视觉反馈：

```
OnDamageReceived(NewHP):
  1. 立即将 HP 条缩放到 NewHP
  2. 在原有 HP 位置留下白色残影
  3. 残影在 0.5s 内逐渐缩小到 NewHP 位置
  4. 残影颜色：白色（Alpha 0.6），在 0.5s 内淡出
```

### Boss HP 条与忍杀节点

Boss 的 DeathblowCount 在 HP 条上显示为节点标记（红色圆点）：

```
HP 条：[████████████████████████████████████]
         ●                     ●
       忍杀节点 #1          忍杀节点 #2

每次忍杀成功 → 对应的节点破碎动画 → 下一节点保持显示
最后一次忍杀 → 所有节点消失 → Boss 名称消失
```

### 危字 UI 规范

| 参数 | 值 |
|------|-----|
| 字体大小 | 屏幕高度的 5% |
| 颜色 | RGB(255, 30, 30) |
| 动画 | 0.15s scale 0.8→1.0 + 透明度 0→1 |
| 位置 | 屏幕中心上方 15% |
| 描边 | 1px 黑色描边 |
| 音效 | 仅由音效系统负责，HUD 不触发音效 |

### 与非战斗状态的切换

```
进入战斗状态：
  ├── 玩家 HUD 元素始终可见（或玩家 HP 不满时显示）
  ├── Boss HUD 元素显示（锁定 Boss 时）
  └── HUD 元素淡入 0.3s

离开战斗状态：
  ├── Boss HUD 元素隐藏（淡出 0.5s）
  ├── 葫芦/回生 HUD 保持显示
  └── 玩家 HP 条满后 2s 自动隐藏
```

### 与其他系统的交互

| 交互系统 | 数据流向 | 说明 |
|----------|---------|------|
| HP & 架势 | 输入 OnHPChanged/OnPostureChanged | HP/架势条更新 |
| 锁定系统 | 输入 OnTargetLocked/OnTargetLost | 锁定标记位置 |
| 危字系统 | 输入 OnPerilousStart/OnPerilousEnd | 危字提示显示/隐藏 |
| 伤药葫芦 | 输入 OnChargesChanged | 葫芦图标更新 |
| 回生系统 | 输入 OnResurrectionChanged | 回生节点更新 |
| 忍杀系统 | 输入 OnDeathblowAvailable | 忍杀标记显示 |
| 本地化 | 依赖本地化文本 | Boss 名称/UI 文本 |

## 公式

### HP 条残影延迟

```
ResidualDelay = 0.15s（延迟后开始缩小残影）
ResidualShrinkDuration = 0.35s（残影缩小到当前 HP 的时间）
```

### Boss HP 条显示时机

```
bShowBossHUD = IsLockedOn(boss) || boss.IsInCombat
// 非锁定但 Boss 在战斗中：半透明显示（alpha 0.6）
// 锁定 Boss：完全不透明
```

## 边界情况

| 场景 | 预期行为 | 理由 |
|------|---------|------|
| Boss HP=0 但尚未忍杀 | Boss HP 条显示为空（0%），架势条保持，忍杀标记出现 | 指示可忍杀状态 |
| 玩家 HP 不满但脱战 | HP 条保持显示直到回满后 2s | 让玩家知道血量状态 |
| 同时多个锁定目标 | 仅显示主锁定目标的 HUD，副目标不显示 HP 条 | 信息不混乱 |
| Boss 阶段切换 | Boss HP 条快速回满（0.5s 过渡动画），忍杀节点 -1 | 视觉反馈阶段切换 |
| 危字与忍杀标记同时出现 | 危字优先显示，忍杀标记在目标身上正常显示 | 两者信息不冲突 |
| 屏幕分辨率变化 | 所有 HUD 元素使用锚定（Anchor）定位，自动适配 | 不同分辨率一致体验 |

## 依赖

| 系统 | 方向 | 依赖性质 |
|------|------|---------|
| HP & 架势 | 依赖事件 | OnHPChanged/OnPostureChanged |
| 锁定系统 | 依赖事件 | 锁定目标信息 |
| 危字系统 | 依赖事件 | 危字显示/隐藏 |
| 伤药葫芦 | 依赖事件 | 使用次数变更 |
| 回生系统 | 依赖事件 | 回生节点状态 |
| 忍杀系统 | 依赖事件 | 忍杀可用通知 |
| 本地化 | 依赖文本 | Boss 名称等 |

## 调优旋钮

| 参数 | 建议默认值 | 安全范围 | 增加的效果 | 减少的效果 |
|------|----------|---------|-----------|-----------|
| HPResidualDelay | 0.15s | 0.1-0.3 | 残影延迟更久 | 残影更快缩回 |
| HPResidualShrinkDur | 0.35s | 0.2-0.5 | 更慢的残影动画 | 更快的残影动画 |
| BossHUDFadeIn | 0.3s | 0.1-0.5 | 更慢的 Boss HUD 出现 | 更快的 Boss HUD 出现 |
| PerilousScaleSpeed | 0.15s | 0.1-0.25 | 更慢的危字放大 | 更快的危字放大 |
| PosturePulseSpeed | 2Hz | 1-3Hz | 架势满时脉冲更快 | 更慢的脉冲 |

## 验收标准

- [ ] 玩家 HP 减少时 HP 条更新 + 白色残影延迟消失
- [ ] 玩家架势变化时架势条正确更新 + 充满时红色闪烁
- [ ] 锁定 Boss 时 Boss HP/架势条 + 名称显示
- [ ] Boss HP 随伤害减少，忍杀节点正确显示
- [ ] 危字触发时屏幕上方居中显示红色危字（0.15s 放大动画）
- [ ] 葫芦次数变更时左上图标正确更新
- [ ] 回生节点状态随消耗/充能正确更新
- [ ] 忍杀条件满足时目标身上显示红色标记
- [ ] 非战斗状态下 Boss HUD 隐藏，玩家 HP 满后 2s 消失
