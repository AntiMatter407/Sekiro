# 忍杀系统

> **状态**: 草稿
> **最后更新**: 2026-05-30
> **支撑的支柱**: 刀刃对抗

## 概述

忍杀（Deathblow/Shinobi Execution）是只狼战斗的终结技。当敌人架势崩坏（PostureBroken）或 HP 归零时，玩家可执行忍杀——一段不可中断的处决演出，结束后敌人死亡。对 Boss 需要多次忍杀（通常 2-3 次）。忍杀期间双方无敌，演出动画由动画系统控制。

## 玩家幻想

红点出现的瞬间——就是现在！按下攻击键，角色跃入处决动画，刀刃穿透敌人要害。演出简短但有力量，让玩家感受到"这场战斗我赢了"的满足感。

## 详细设计

### 核心规则

1. 忍杀触发条件：敌人处于 PostureBroken 或 HP=0 状态
2. UI 提示：敌人身上出现红色忍杀标记
3. 按下攻击键（靠近可忍杀敌人时）→ 触发忍杀
4. 忍杀演出期间双方无敌、静止（锁定 Root Motion）
5. 演出结束 → 敌人死亡（或扣除一次忍杀计数，Boss 进入下一阶段）
6. Boss 有多条命时（DeathblowCount > 1），每次忍杀扣除一次计数

### 忍杀触发流程

```
1. 敌人 PostureBroken or HP=0
2. Red Dot UI 提示出现（持续 1.0s 后逐渐消失）
3. 玩家靠近（距离 < DeathblowRange）
4. 玩家按攻击键
5. → 进入忍杀演出
6.   → 双方移动到演出起始位置
7.   → 播放忍杀 Montage
8.   → Boss：扣除一次 DeathblowCount
9.     ├── DeathblowCount > 0 → 进入下一阶段（HP 回满，架势清空，新招式）
10.    └── DeathblowCount = 0 → 敌人死亡
```

### 忍杀范围

| 参数 | 值 |
|------|-----|
| 忍杀触发距离 | 300 UE单位 |
| 忍杀有效角度 | 玩家朝向与目标方向 ±60° |
| 提示持续时间 | 1.0s（之后红色标记逐渐透明） |

### Boss 多阶段

Boss 通过 DeathblowCount 控制需要几次忍杀：

```
FSKBossData:
  DeathblowCount = 2  // 需要 2 次忍杀
  PhaseHPThresholds = [0.5]  // 1 次 HP 阈值（另一条命）
```

第一阶段：HP 100% → 打崩架势 → 忍杀 1
第二阶段：HP 恢复到 100%，架势清空，启用Phase 2 攻击列表 → 打崩架势 → 忍杀 2 → 死亡

### 忍杀演出类型

| 类型 | 条件 | 演出时长 |
|------|------|---------|
| 地面忍杀 | 双方在地面 | 2.0s |
| 空中忍杀 | 玩家跳跃中 | 2.5s |
| 背后忍杀 | 潜行（第一阶段不涉及） | 1.5s |

### 与其他系统的交互

| 交互系统 | 数据流向 | 说明 |
|----------|---------|------|
| HP & 架势 | 输入 PostureBroken/HP=0 | 忍杀触发条件 |
| 动画系统 | 输出忍杀 Montage | 演出动画 |
| Boss AI | 输出死亡/阶段切换 | Boss 状态变更 |
| 战斗 HUD | 输出忍杀标记显示 | Red Dot UI |
| 输入系统 | 输入攻击键 | 触发忍杀 |
| 战斗音效 | 输出忍杀事件 | 忍杀音效 |
| 战斗特效 | 输出忍杀事件 | 处决特效 |

## 公式

### 忍杀触发检查

```
bCanDeathblow = Target.IsPostureBroken() || Target.HP == 0
               && Distance(Player, Target) <= DeathblowRange
               && Angle(Player.Forward, Target - Player) <= MaxAngle
               && InputPressed(IA_Attack)
```

### Boss 生命计数

```
DeathblowCount_Remaining -= 1
if DeathblowCount_Remaining > 0:
    Boss.HP = MaxHP
    Boss.Posture = 0
    Boss.Phase += 1
else:
    Boss.Die()
```

## 边界情况

| 场景 | 预期行为 | 理由 |
|------|---------|------|
| 多个敌人同时可忍杀 | 只对最近的有效目标执行（角/距权重），演出期间其他敌人可行动 | 忍杀不提供全局无敌 |
| 忍杀中被打断 | 不可打断——忍杀期间双方无敌 | 演出完整性 |
| 忍杀触发距离临界 | 距离在范围内但玩家面向相反方向 → 不触发 | 需要面向目标 |
| 目标在坡上/坡下 | 高度差 ≤ 150 UE单位时允许，演出时自动对齐位置 | 地形宽容 |
| Boss 最后一条命被忍杀 | DeathblowCount=0 → 触发 Boss 死亡动画而非阶段切换 |

## 调优旋钮

| 参数 | 建议默认值 | 安全范围 | 增加的效果 | 减少的效果 |
|------|----------|---------|-----------|-----------|
| DeathblowRange | 300 UE单位 | 200-400 | 更远可忍杀 | 更近 |
| MaxDeathblowAngle | 60° | 45°-90° | 更宽容的角度 | 需要更精确的面向 |
| PromptDuration | 1.0s | 0.5-2.0 | 提示更久 | 提示更短 |
| DeathblowAnimationDuration | 2.0s | 1.5-3.0 | 更长演出 | 更短演出 |

## 验收标准

- [ ] 敌人架势崩坏后出现红色忍杀标记
- [ ] 靠近可忍杀敌人 + 按攻击键 → 触发忍杀演出
- [ ] 忍杀演出期间双方无敌、静止
- [ ] Boss DeathblowCount=2 → 第一次忍杀后进入下一阶段（HP回满、架势清空）
- [ ] Boss DeathblowCount=0 → 忍杀后死亡
- [ ] 多个可忍杀敌人时，忍杀最近的目标
- [ ] 忍杀演出不可被外部攻击中断
