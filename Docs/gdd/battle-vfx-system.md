# 战斗特效系统

> **状态**: 草稿
> **最后更新**: 2026-05-30
> **支撑的支柱**: 精确节奏、刀刃对抗

## 概述

战斗特效（Battle VFX）系统负责战斗中所有视觉特效的触发和管理——弹刀火花粒子、危字 UI 特效、忍杀处决特效、回生特效、受击血液/火花、架势崩坏特效等。特效提供战斗的视觉重量感和反馈清晰度，帮助玩家在混乱的战斗中理解发生了什么。

## 玩家幻想

弹刀瞬间迸发的橙色火花——不只是好看，它传达了一个信息：你弹刀成功了。忍杀时屏幕边缘的红色暗角让处决充满仪式感。危字闪现时屏幕微妙的红色滤镜让玩家本能地紧张起来。好的特效不是装饰，是信息。

## 详细设计

### 核心规则

1. 特效通过事件系统触发——游戏系统发送视觉事件，VFX 系统决定播放什么
2. 每个 VFX 事件携带位置、方向和参数（如强度、类型）
3. 特效实例通过对象池管理，避免频繁创建/销毁
4. 特效有 LOD 系统——距离远时使用简化版或跳过
5. 屏幕特效（后处理）仅在战斗关键时刻使用，不持续占用

### 弹刀火花特效（重点）

弹刀火花是出现最频繁的特效，需要特别优化：

```
弹刀火花参数：
  ├── 基础粒子数：8-12
  ├── 粒子颜色：橙色偏白（#FF9930 → #FFCC80）
  ├── 粒子大小：5-10 UE 单位
  ├── 生命周期：0.15-0.30s（随机）
  ├── 速度：200-400 UE单位/s（从碰撞点向外扩散）
  ├── 扩散方向：锥形范围 ±60°（垂直于碰撞面法线）
  ├── 重力影响：轻微下落（50 UE单位/s²）
  └── LOD1 (近): 12 粒子 | LOD2 (中): 6 粒子 | LOD3 (远): 跳过

弹刀强度分级：
  ├── 普通弹刀：基础火花（橙色，8粒子）
  ├── 连续弹刀（第3次+）：加强火花（橙金色，12粒子）
  └── Boss弹刀玩家：镜像火花（白色偏蓝，8粒子）
```

### 危字 UI 特效

```
危字特效参数：
  ├── 字体："危"（日文汉字，红色 #FF1E1E）
  ├── 出现动画：
  │   ├── 0.00-0.10s：Scale 0.5 → 1.2，透明度 0 → 1
  │   └── 0.10-0.15s：Scale 1.2 → 1.0（回弹）
  ├── 消失动画：透明度 1 → 0，0.2s
  ├── 屏幕暗角（后处理）：
  │   ├── 暗角颜色：黑色，透明度 0-15%
  │   ├── 暗角范围：屏幕边缘向内 15%
  │   └── 过渡时间：0.3s 进出
  └── 与危字音效同步（通过事件系统协调）
```

### 忍杀处决特效

```
忍杀特效分层：
  第一层 - 全屏后处理：
    ├── 屏幕边缘暗角（黑色，透明度 0-30%）
    ├── 色彩饱和度降低 20%
    └── 过渡时间：0.3s 进入，0.5s 退出

  第二层 - 命中瞬间粒子：
    ├── 血液喷射粒子（从命中点，15-20 粒子）
    ├── 粒子颜色：红色系（#CC0000 → #660000）
    ├── 生命周期：0.3-0.5s
    └── 速度：300-600 UE单位/s

  第三层 - 武器轨迹：
    └── 忍杀动画中的武器挥砍轨迹（Sword Trail 变体，红色调）
```

### 特效对象池

所有频繁触发的粒子特效使用对象池管理：

```
对象池配置：
  ├── VFX_Deflect_Spark:      池大小 12（同时最多 4 个活跃，12 预分配）
  ├── VFX_Guard_Spark:        池大小 6
  ├── VFX_Attack_Hit_Blood:   池大小 8
  ├── VFX_Sword_Trail:        池大小 4
  └── VFX_Posture_Broken:     池大小 3

对象池行为：
  ├── 请求 → 返回第一个非活跃实例
  ├── 池空 → 回收最早活跃的实例（低优先级）或跳过（高优先级不回收）
  └── 每 30s 清理超出基础池大小 2× 的未使用实例
```

### 特效 LOD 系统

| LOD 级别 | 距离条件 | 行为 |
|----------|---------|------|
| LOD1（完整） | 距离 < 1000 | 完整粒子数 + 完整生命周期 |
| LOD2（简化） | 1000 ≤ 距离 < 2000 | 减半粒子数 + 缩短生命周期 |
| LOD3（最小） | 2000 ≤ 距离 < 3000 | 最小粒子数（2-3）+ 静态精灵替代 |
| LOD4（跳过） | 距离 ≥ 3000 | 不播放 |

例外：全屏后处理、UI 特效、忍杀特效不受 LOD 影响——始终完整播放。

| 交互系统 | 数据流向 | 说明 |

| 忍杀系统 | 输入 Deathblow 事件 | 忍杀特效 |

## 公式

### 弹刀火花扩散速度

```
ParticleVelocity = DeflectSparkBaseSpeed × (1 + ConsecutiveDeflectBonus × 0.2)
// 连续弹刀的火花扩散更快更猛
```

### 特效池回收策略

```
if PoolExhausted and NewRequest.Priority >= OldestActive.Priority:
    Recycle(OldestActive)  // 回收最早的活跃实例
    Spawn(NewRequest)
else:
    Skip(NewRequest)       // 跳过新请求，输出 Warning
```

## 边界情况

| 场景 | 预期行为 | 理由 |
|------|---------|------|
| 连续弹刀高频触发火花 | 对象池内 12 个实例轮换使用，不创建新实例 | 性能稳定 |
| 弹刀 + 受击同时发生 | 两种特效都播放（不同位置，不同对象池） | 信息不矛盾 |
| 忍杀演出期间其他特效 | 忍杀全屏后处理叠加，非忍杀粒子正常播放但不被后处理遮挡 | 分层渲染 |
| 危字特效 + 危字音效不同步 | VFX 和 SFX 系统各自触发，允许 ±1 帧偏差 | 人类感知容差内 |
| 特效对象池全部活跃 | 高优先级可回收低优先级实例；同优先级则跳过新请求 | 性能保护 |
| 两个敌人在 LOD2 距离同时弹刀 | 各播放简化版火花（各 6 粒子），总粒子数受控 | 粒子预算管理 |

## 调优旋钮

| 参数 | 建议默认值 | 安全范围 | 增加的效果 | 减少的效果 |
|------|----------|---------|-----------|-----------|
| DeflectSparkCount | 8 | 6-15 | 更多粒子、更华丽 | 更少粒子、更清晰 |
| DeflectSparkSpeed | 300 | 200-500 | 火花扩散更远 | 火花更集中 |
| PerilousKanjiScale | 5% 屏幕高度 | 3-7% | 更大的危字 | 更小的危字 |
| DeathblowVignetteAlpha | 0.3 | 0.2-0.5 | 更黑的暗角 | 更淡的暗角 |
| ParticlePoolMaxIdle | 2× 基础大小 | 1.5-3× | 更多待机实例（内存） | 更频繁创建/销毁 |
| VFXLOD1Distance | 1000 | 800-1500 | 更远看完整特效 | 更早简化 |

## 验收标准

- [ ] 弹刀成功时在碰撞点生成橙色火花粒子
- [ ] 连续弹刀（3次+）火花粒子数量和速度增加
- [ ] 格挡火花与弹刀火花有视觉差异（更小、更暗）
- [ ] 危字触发时屏幕居中显示放大动画 + 屏幕边缘暗角
- [ ] 忍杀演出期间全屏暗角 + 命中瞬间血液粒子
- [ ] 回生期间完整播放回生粒子特效
- [ ] 特效对象池正确回收和复用，无内存泄漏
- [ ] LOD 系统按距离正确切换特效等级
- [ ] 全屏后处理（危字暗角、忍杀暗角）正确进出过渡
