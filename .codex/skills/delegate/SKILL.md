# /delegate — 复杂提问处理

## 触发方式

| 命令 | 作用 |
|------|------|
| `/delegate <复杂问题>` | 开启新 subagent，净化上下文处理该问题 |

## 适用场景

1. **多步骤复杂任务** — 需要读代码、写代码、验证等多个步骤
2. **上下文污染** — 主对话历史太长，需要干净上下文重新聚焦
3. **独立子问题** — 可以从主流程中独立出来的问题
4. **需要专注分析** — 避免主对话中其他信息干扰

## 工作流

```
/delegate <复杂问题>
      │
      ▼
  1. 将问题完整传递给 subagent（包含项目上下文：AGENTS.md、技能、规则）
  2. subagent 在干净上下文中独立工作：
     - 探索相关代码
     - 设计/实现方案
     - 直接修改文件
  3. subagent 完成后，返回结果到主对话
  4. 主对话继续推进
```

## subagent 配置

- **类型**：默认 agent，继承当前模型
- **上下文**：fork 当前对话（保留项目知识，丢弃历史噪音）
- **权限**：完整的文件读写权限（与主对话相同）
- **技能**：继承项目技能（aibridge、sekiro-asset-import 等）

## 使用示例

```
用户: 这个 SKCharacter 的移动逻辑有几个 bug，帮我分析并修复
  ↓
/delegate 分析 SKCharacter.cpp 移动逻辑的 bug 并修复

→ subagent 读取文件 → 分析问题 → 修复代码 → 验证 → 返回结果
```

## 规则

- **一个问题一个 subagent**：每次只处理一个独立问题
- **明确边界**：告诉 subagent 具体要处理什么、不要动什么
- **完成后关闭**：subagent 返回结果后自动关闭，释放资源
- **结果集成**：主对话收到结果后继续推进
